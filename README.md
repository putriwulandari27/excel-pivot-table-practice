# 📊 Latihan Analisis Data dengan Pivot Table (Microsoft Excel)

Proyek portofolio SMK ini berisi latihan pengolahan data mentah transaksi menggunakan **Pivot Table** di Microsoft Excel untuk menghasilkan laporan rekapitulasi yang ringkas dan fleksibel.

---

## 🛠️ Tools & Fitur yang Digunakan
- **Tools:** Microsoft Excel / Google Sheets
- **Fitur Utama:** Pivot Table, Data Filtering (Tahun), Rows & Columns Grouping, Sum Values.

---

## 📋 Hasil Analisis Pivot Table

### 1. Rekapitulasi Baris & Kolom (Barang vs Suplier)
- **Rows (Baris):** Daftar Nama Barang (`Cabai`, `Kunyit`, `Bawang Merah`, `Bawang Putih`, `Kencur`, `Jahe`).
- **Columns (Kolom):** Nama Suplier Toko (`Laris`, `Satu`, `Sumber Rezeki`).
- **Values (Nilai):** Total Jumlah (`Sum of Jumlah`).
- **Hasil:** Memudahkan pemantauan total unit barang yang disuplai oleh masing-masing toko secara otomatis tanpa rumus manual.

### 2. Penerapan Filter Interaktif
- **Filter (Tahun):** Ditambahkan pada bagian atas Pivot Table.
- **Hasil:** Laporan dapat disaring berdasarkan tahun tertentu (misal: hanya melihat transaksi tahun `2021` atau `2022`).
